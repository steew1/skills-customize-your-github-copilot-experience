# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a command-line Hangman game that lets a player guess letters to reveal a hidden word, practicing string manipulation, loops, conditionals, and user input handling.

## 📝 Tasks

### 🛠️ Implement Hangman Game

#### Description
Create a playable Hangman game in Python. The program should choose a secret word and prompt the player to guess letters until they either reveal the word or run out of attempts.

#### Requirements
Completed program should:

- Randomly select a secret word from a predefined list
- Display the current word progress with underscores for unknown letters and revealed letters for correct guesses (for example: _ a _ g _ a _)
- Accept single-letter guesses (case-insensitive) and ignore repeated guesses
- Track and display the number of remaining incorrect attempts
- End the game when the word is fully guessed or attempts are exhausted, showing a clear win or lose message
- Provide clear prompts and basic input validation
- Use the provided `starter-code.py` as scaffolding and reference
