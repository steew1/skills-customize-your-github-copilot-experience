# 📘 Assignment: Building a Personal Portfolio Website

## 🎯 Objective

Create a single-page portfolio website that showcases your projects and skills using HTML for structure and CSS for styling. You'll learn fundamental web markup, semantic HTML, and responsive design principles.

## 📝 Tasks

### 🛠️ Build HTML Structure & Content

#### Description
Create a well-structured HTML page for a personal portfolio. Use semantic HTML elements to organize content including a header, navigation, sections for projects and skills, and a footer.

#### Requirements
Completed program should:

- Use semantic HTML5 elements (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`)
- Include a navigation menu with internal links to page sections
- Create an "About" section with a brief introduction and profile information
- Create a "Projects" section showcasing at least 3 past projects with descriptions
- Create a "Skills" section listing programming languages, tools, and technologies
- Include contact information and links (email, GitHub, LinkedIn, etc.) in the footer
- Use proper heading hierarchy (`<h1>`, `<h2>`, etc.)
- Add meaningful alt text to any images
- Use the provided `starter-code.html` as scaffolding

### 🛠️ Style with CSS

#### Description
Apply CSS styling to create an attractive, professional-looking portfolio. Focus on typography, layout, colors, and spacing to make the site visually appealing.

#### Requirements
Completed program should:

- Define a consistent color scheme (at least 3 colors)
- Style typography with appropriate font families and sizes
- Create a responsive layout using Flexbox or CSS Grid
- Style navigation with hover effects and active link states
- Add padding and margin for proper spacing throughout
- Include a background image or gradient (optional but recommended)
- Use CSS classes effectively for reusable styles
- Ensure the portfolio is viewable and functional in a modern web browser
- Use the `<style>` tag in HTML or link an external `styles.css` file

### 🛠️ Add Responsive Design (Optional)

#### Description
Make your portfolio responsive so it looks good on mobile devices, tablets, and desktops using media queries.

#### Requirements
Completed program should:

- Implement media queries for at least two breakpoints (mobile and desktop)
- Adjust layout and font sizes for smaller screens
- Test and verify the portfolio displays correctly on mobile devices
- Consider navigation changes for mobile (e.g., hamburger menu or simplified nav)
